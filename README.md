# AuroraTone
_An elegant, mobile-first web music player — zero installs, plays your local files privately in the browser._

AuroraTone is a single-file, iOS-inspired music player you can open by double-clicking. It supports uploading an entire folder of songs, adding individual files, and drag-and-drop. Each track gets a tasteful, auto-generated gradient cover, and the UI is optimized to fill **90% of the screen** on phones and desktops.

---

## ✨ Features
- **Click-to-run:** one self-contained HTML file. No build, no dependencies.
- **Upload Folder** _(recursive)_: load a whole music folder at once (Chromium browsers).
- **Add Music** + **Drag & Drop**: pick individual files or drop them into the app.
- **Polished, iOS-style UI:** mini player, big “Now Playing”, clean typography, modern controls.
- **Random cover art per track:** deterministic gradient artwork (no internet required).
- **Playback controls:** play/pause, next/prev, seek bar with scrubbing, volume.
- **Modes:** shuffle, repeat-one, optional autoplay.
- **Responsive:** mobile and desktop layouts; app uses ~**90vw × 90vh**.
- **Media keys:** supports system/media-session controls on compatible browsers.
- **Privacy-first:** your audio never leaves the device.

> Supported formats depend on your browser. Common types: `.mp3`, `.m4a`, `.aac`, `.ogg`, `.wav`, `.flac`.

---

## 🚀 Quick Start
1. Download `pro_music_mobile_webapp_90.html` (the AuroraTone file).
2. Double-click to open it in your browser.
3. Click **Upload Folder** to add your entire music folder  
   — or use **Add Music** / drag-and-drop to add individual files.
4. Press ▶️ and enjoy.

> **Tip:** For best results on Windows, use **Chrome** or **Edge**. (Firefox doesn’t fully support folder uploads via `webkitdirectory` yet; individual file upload still works.)

## ⌨️ Keyboard Shortcuts
- **Space** — Play/Pause  
- **← / →** — Seek −5s / +5s

---

## 🧠 How it works (high-level)
- Everything runs client-side in your browser.
- Folder uploads use `<input type="file" webkitdirectory>` (recursively collects files).
- Per-track cover art is generated by a small SVG function seeded by the filename, so each song gets a consistent, “random” gradient.
- No analytics, no network calls, no servers.

---

## 🛠 Customization
Open the HTML file and look for these sections:

- **Color palette / theme:** tweak CSS variables at the top of the `<style>` block.
- **Random covers:** edit the `palettes` array and `coverDataURI()` in the `<script>` to change gradient styles.
- **Layout size:** the `.app` container uses `width: 90vw; height: 90vh;` — adjust as you like.

## 🧪 Browser Support
- **Recommended:** Chrome 90+, Edge 90+  
- **Works with limitations:** Firefox (no folder upload; use Add Music)  
- **Mobile:** Chrome/Edge on Android, Safari/Chrome on iOS (file picker UX may vary by OS)
